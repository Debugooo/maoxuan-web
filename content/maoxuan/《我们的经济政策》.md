# 《我们的经济政策》｜资源治理框架（Policy → Allocation）

一句硬核结论：经济政策不是口号，是“资源如何产生、如何分配、如何激励、如何控风险”的可执行规则；没有政策，组织只能靠人治与临时救火。

## 01 局势快照（20%）

### 历史坐标

- 写作时间：1934-01（通行版本仅标到月份；报告在 1934-01-24 至 1934-01-25 作出）
- 写作任务：在封锁与战争条件下，明确“经济政策”的原则、结构与优先级：集中供给战争，同时改良民众生活并构建长期前提。
- 时间线（事件）：
  - 1933-08-12：提出“必须注意经济工作”，把经济战线提升为战争胜负条件。
  - 1933-09：第五次“围剿”进入正式阶段（通行记载常以月份表述），经济封锁与财政压力加剧。
  - 1934-01-22：第二次全国工农兵代表大会在瑞金召开（文库说明提及），政策体系集中统一。
  - 1934-01-24：在大会上作经济政策报告（文库说明提及），提出原则与三种经济形态。
  - 1934-01-27：进一步强调“群众生活与工作方法”，把政策落地与群众利益绑定。
- 资料来源：
  - https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-193401.htm

### 金句与摘录

- “我们的经济政策的原则，是进行一切可能的和必须的经济方面的建设，集中经济力量供给战争，同时极力改良民众的生活……造成将来发展到社会主义的前提。”
- “我们的经济建设的中心是发展农业生产，发展工业生产，发展对外贸易和发展合作社。”
- “在目前的条件之下，农业生产是我们经济建设工作的第一位。”
- “水利是农业的命脉，我们也应予以极大的注意。”
- “我们有计划地组织人民的对外贸易，并且由国家直接经营若干项必要的商品流通……现在是异常需要的了。”
- “现在我们的国民经济，是由国营事业、合作社事业和私人事业这三方面组成的。”
- “合作社经济和国营经济配合起来，经过长期的发展，将成为经济方面的巨大力量。”
- “贪污和浪费是极大的犯罪。”

### 核心思想（可调用要点）

- 把政策写成可执行规则：原则→优先级→口径→组织形态→资金来源→风控红线。
- 先保生存再谈扩张：集中资源保障核心任务（当代等价物：现金流与交付系统）。
- 四个抓手：农业/工业/贸易/合作社，分别对应“供给、产能、流通、组织化”。
- 三种经济形态并存：国营、合作社、私人并进，用规则争取“领导权”而非一刀切。
- 反腐与节省是基础设施：没有信用与纪律，任何政策都会被执行层面吃掉。

### 核心问题

当组织要持续运转，资源必须规则化：谁创造价值，谁获得激励；谁承担风险，谁拥有权责。

### 现代映射

- 创业：定价、补贴、佣金、成本、现金流与扩张节奏
- 职场：预算、资源、绩效与激励机制
- 家庭：预算分配与共同目标

### 长案例（沉浸式）

你公司增长很好但现金流持续恶化。原因不是“业务不好”，而是政策错：为了短期指标，给了高补贴、低毛利，交付成本还不可控。你把政策重写：先明确单位经济口径与红线，再分配预算与激励；把扩张与止损写成规则。三个月后，增长更稳，组织也不再靠拍脑袋分资源。

### 关键概念

- 政策：可执行的规则（口径、流程、权责、奖惩、止损）。
- 激励一致：做对的事能获得确定收益。
- 风险红线：触线必须停止或收缩。

### 可操作结论

1. 写出你组织的“单位经济口径”（成本/收益/时间窗）。
2. 写出三条红线（触线即止损）。
3. 写出预算与激励分配规则（公开透明）。

## 02 思维骨架（40%）

### 论证链

1. 资源稀缺环境下，必须有政策来统一行动。
2. 政策的核心是口径一致与激励一致。
3. 没有红线与止损，扩张会把组织拖死。

### 误区

- 指标驱动但口径不清
- 激励与实际价值创造脱钩

## 03 知识图鉴（60%）

### 模板：资源政策五件套

- 口径：单位经济/成本归集/收益确认
- 分配：预算规则、优先级
- 激励：奖金/佣金/晋升与指标绑定
- 风控：红线、止损、审批
- 复盘：周期、指标、纠偏机制

### 文本图：政策—执行闭环

```text
政策(口径/激励/红线) -> 执行 -> 结果 -> 复盘 -> 政策迭代
```

## 04 底层解码（80%）

### 关键约束

- 经济政策决定组织的“真实行为”，比文化口号更硬。
- 政策必须能被执行与审计，否则等于没有。

## 05 认知破局（100%）

### 模型A：单位经济红线

- 输入：业务模型与数据口径
- 步骤：定义单位投入/单位产出 → 设三条红线（毛利/回收期/交付成本）→ 建日报/周报监控
- 校验：红线触发次数是否下降
- 止损：红线反复触发 → 停止扩张并重做模型

### 模型B：预算优先级排序

- 输入：所有项目清单
- 步骤：按“胜负指标贡献×可控性×风险”打分 → 只保留 TopN → 剩余全部收缩
- 校验：资源更集中、返工更少
- 止损：评分体系被操纵 → 改用更硬证据（数据与交付）

### 六场景推演

- 创业：先设单位经济红线再做增长；原则：红线先于野心。
- 职场：预算规则公开透明；原则：口径一致减少内耗。
- 人生：先设个人财务红线；原则：续航优先。
- 人际：资源与边界透明；原则：规则减少误会。
- 家庭：家庭预算与目标一致；原则：共同规则。
- 教育：资源投入可复盘；原则：避免无效投入。

### 复盘模板

- 口径：本周单位经济是什么？
- 红线：触发了吗？原因？
- 预算：Top3 投入是什么？证据？
- 激励：是否诱导了错误行为？
- 调整：下周政策改哪条？

### 练习题

1. 写出你的单位经济口径与三条红线。
2. 给你的项目清单做一次预算优先级排序，并砍掉 30%。
3. 找出一个“激励错配”的例子，并写出纠偏规则。
