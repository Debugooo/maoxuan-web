# 《井冈山的斗争》｜边打边建操作系统（Fight → Build）

一句硬核结论：在高压对抗里，真正决定胜负的是“补给与组织”，不是一时的战斗英雄主义。

## 01 局势快照（20%）

### 历史坐标

- 写作时间：1928-11-25
- 处境：外部围剿、内部供给紧张、需要在机动中建立稳定结构。
- 任务：把“活下来”与“发展”同时做到，且不能靠一次性豪赌。
- 时间线（事件）：
  - 1927-09-09：秋收起义爆发，转入以农村为依托的武装斗争实践。
  - 1928-04-28：朱德、毛泽东井冈山会师，力量与路线开始系统整合。
  - 1928-06-23：龙源口战斗获胜（文中记），边界割据进入扩展期。
  - 1928-08-30：井冈山保卫战（文中记），在强攻下保住根据地。
  - 1928-09-13：遂川击败追兵并缴枪（文中记），突破围追压力。
  - 1928-10-01：宁冈作战获胜并收复宁冈全县（文中记），恢复整块区域。
  - 1928-11-25：写给中共中央的报告成文，总结“边打边建”的条件与节奏。
- 资料来源：
  - https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-19281125.htm

### 金句与摘录

- “工农武装割据的存在和发展，还需要具备下列的条件：（1）有很好的群众；（2）有很好的党；（3）有相当力量的红军；（4）有便利于作战的地势；（5）有足够给养的经济力。”
- “所谓割据，必须是武装的。”
- “官长不打士兵，官兵待遇平等，士兵有开会说话的自由，废除烦琐的礼节，经济公开。”
- “红军像一个火炉，俘虏兵过来马上就熔化了。”
- “中国不但人民需要民主主义，军队也需要民主主义。”
- “军队内的民主主义制度，将是破坏封建雇佣军队的一个重要的武器。”
- “红军所以艰难奋战而不溃散，‘支部建在连上’是一个重要原因。”
- “我们三年来从斗争中所得的战术……‘分兵以发动群众，集中以应付敌人。’”

### 核心思想（可调用要点）

- 把“持续作战”工程化：群众、组织、核心力量、地形/场域、供给，缺一不可。
- 以供给与损耗管理替代英雄主义：先算能打多久、断供怎么止损，再谈扩张。
- 以组织治理保续航：纪律、训练、干部补给与信息机制，决定能否在压力下不崩盘。
- 用制度生产战斗力：平等、公开、民主，降低内耗并提升协同与凝聚。
- 节奏切换：在“统治阶级暂稳/破裂”两种外部周期中采用不同推进策略，避免分兵冒进。
- 把战术写成可复用规则：分兵发动群众、集中应付敌人；短期开合，长期经营中心区域。

### 博弈版图

- 外部压力：围剿、封锁、情报渗透。
- 内部压力：粮秣不足、队伍纪律、群众关系、干部能力参差。
- 关键矛盾：机动作战 vs 稳定建设，必须找到节奏切换。

### 现代映射

- 创业：在资金紧、竞争强时，一边交付一边建体系。
- 职场：在资源不友好环境里，一边拿结果一边固化流程。

### 长案例（沉浸式）

你做的是“弱势团队逆袭”。一旦你只盯冲刺与胜利叙事，马上会在补给、人员与情报上崩盘。你把节奏改为：短周期交付（打）+ 固化流程（建）+ 建立反馈与纪律（稳）+ 小范围试错（探）。你不再追求每次都赢，而是追求“每轮都不死且变强”。

### 关键概念

- 边打边建：交付与建设同步推进的节奏设计。
- 补给：现金流/产能/人力/信息的持续输入。
- 情报：对环境变化的预警与对风险的提前识别。
- 纪律：降低损耗与内耗的组织规则。

### 可操作结论

1. 把“补给线”写出来：钱从哪来、多久断、断了怎么办。
2. 把“节奏”写出来：一周交付什么、两周固化什么、每月复盘什么。
3. 把“情报”写出来：最早的风险信号是什么，谁负责收集与升级。

## 02 思维骨架（40%）

### 论证链

1. 高压对抗不允许长期无补给的英雄主义。
2. 机动可以避开硬碰，但不能替代建设与治理。
3. 纪律与群众关系决定续航与安全。
4. 节奏切换决定能否在压力中持续积累。

### 误区

- 只打不建：交付很多但不可复制，换人就崩。
- 只建不打：体系很美但缺结果，资源被撤走。

### 落地流程

```text
保命指标(补给) -> 周期性交付 -> 固化流程 -> 情报预警 -> 止损规则 -> 复盘升级
```

## 03 知识图鉴（60%）

### 清单：边打边建节奏表

- 每周：一个硬交付（可展示、可验收）
- 每两周：固化一个流程（模板/脚本/角色分工）
- 每月：复盘一次损耗（时间/钱/人/信任）

### 文本图：战斗—建设双循环

```text
交付循环(拿结果) -> 换资源
建设循环(固化流程) -> 降损耗
两者互相供养：没有交付就没资源，没有建设就越打越弱
```

## 04 底层解码（80%）

### 关键约束

- 信息不对称：风险常在爆发前就有信号。
- 资源稀缺：每次错误都会放大。

### 适用/失效

- 适用：创业保命期/逆风项目/组织边缘团队。
- 失效：稳定期若仍按战时节奏会造成长期疲劳。

## 05 认知破局（100%）

### 模型A：补给线压力测试

- 输入：现金流/产能/人力/关键依赖
- 步骤：找出 3 个“断供点” → 为每个断供点写替代方案 → 设预警阈值
- 校验：预警能否在断供前 7 天触发
- 止损：连续触发但无动作 → 立即缩编或换战场

### 模型B：双循环节奏（打/建）

- 输入：当周目标、当月治理项
- 步骤：本周交付 1 件硬结果 + 本周固化 1 个流程/模板
- 校验：交付可验收，流程可复用
- 止损：连续两周只打不建/只建不打 → 强制调整节奏

### 六场景推演

- 创业：先保供给→再做增长；风险：扩张过早；原则：先不死再求大。
- 职场：先拿可见成果→再谈流程；风险：只写方案；原则：结果换资源。
- 人生：先保健康/现金→再追理想；风险：多线崩盘；原则：节奏切换。
- 人际：冲突先稳边界→再谈关系；风险：情绪耗尽；原则：规则优先。
- 家庭：先定分工→再谈情绪；风险：无节奏；原则：小循环复盘。
- 教育：先改环境→再讲道理；风险：只抓分数；原则：长期续航。

### 复盘模板

- 本月补给：剩余多久？最大断供点？
- 本周交付：最硬的结果是什么？
- 本周建设：固化了什么流程？
- 风险信号：最早预警是什么？
- 下轮节奏：加速/降速/缩编/转向

### 练习题

1. 写出你当前的三条补给线，并做一次压力测试。
2. 设定一个“双循环节奏”，连续执行两周并复盘损耗。
3. 列出你最可能被“情报缺失”击穿的风险点，并定义预警信号。
