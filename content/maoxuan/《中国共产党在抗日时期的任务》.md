# 《中国共产党在抗日时期的任务》｜阶段任务管理（Mission → Focus）

一句硬核结论：阶段切换时最怕“任务爆炸”；必须明确主任务、次任务与底线，并把组织能力建设嵌入执行节奏。

## 01 局势快照（20%）

### 历史坐标

- 写作时间：1937-05-03
- 写作任务：在民族危机与国内关系重组的阶段，明确主次矛盾与阶段中心任务，把“和平—民主—抗战”串成可执行路线。
- 时间线（事件）：
  - 1931-09-18：九一八事变，民族矛盾显著上升（文中明确提及）。
  - 1935-12-09：一二九运动爆发，救亡运动进入新时期（文中明确提及）。
  - 1936-12-12：西安事变爆发，国内和平与统一战线窗口打开（文中提及一系列步骤）。
  - 1937-05-03：提出抗日时期任务与民主问题，把“争取民主”定为当前阶段中心一环。
  - 1937-05-08：围绕报告的讨论结论发表（同卷相关篇目），进一步强调“民主即抗日保证”。
  - 1937-07-07：全面抗战爆发，阶段任务进入实战兑现。
- 资料来源：
  - https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-19370503.htm

### 金句与摘录

- “由于中日矛盾成为主要的矛盾、国内矛盾降到次要和服从的地位……形成了目前形势的新的发展阶段。”
- “我们的统一战线应当以抗日为目的，不是同时反对一切帝国主义。”
- “我们的统一战线是包括资产阶级及一切同意保卫祖国的人们的，是举国一致对外的。”
- “争取民主，是目前发展阶段中革命任务的中心一环。”
- “抗战需要人民的动员，没有民主自由，便无从进行动员。”
- “政治制度的民主改革和人民的自由权利，是抗日民族统一战线纲领上的重要部分。”
- “让步是有限度的……超过这种限度是不许可的。”
- “共产党、国民党、全国人民，应当共同一致为民族独立、民权自由、民生幸福这三大目标而奋斗。”

### 核心思想（可调用要点）

- 先判主次矛盾，再定任务树：主要矛盾决定主任务链，其他矛盾转为可调节与服从项。
- 用“中心一环”收敛任务爆炸：把资源与节奏围绕中心任务组织，避免平均用力。
- 联盟要带条件与边界：合作同时保留独立性与批评自由，避免把主导权交出去。
- 民主是动员基础设施：没有自由与制度通道，就无法组织群众、巩固和平与持续抗战。
- 战略让步可换大局：让步必须可量化、有边界、能换来更大共同目标的实现条件。

### 核心问题

当外部环境发生巨大变化，任务会成倍增加：合作、动员、建设、斗争、舆论、治理同时发生。你如何不被任务吞没？

### 现代映射

- 创业：政策/市场突变后，既要扩盟又要交付，还要搭团队与制度
- 职场：组织调整/战略转向后，项目、协作与舆论同时变化

### 长案例（沉浸式）

公司进入新阶段：要做生态合作。你团队突然多了十个任务：对外合作、对内协调、产品迭代、合规、品牌、售后。你如果平均用力，所有事都做不成。你用阶段任务管理：把主任务定为“建立可复制合作模型并跑通一个标杆”，次任务是“内部流程固化”，底线是“现金流与交付稳定”。所有项目围绕这三条排优先级，任务爆炸被收敛。

### 关键概念

- 主任务：决定胜负指标的那一条任务链
- 次任务：为主任务服务的支撑链
- 底线：触线即止损/收缩（避免崩盘）
- 能力建设：把方法、流程、训练固化成组织资产

### 可操作结论

1. 写出本阶段主任务（1 条）+ 胜负指标（1 条）。
2. 写出三条底线（资源/风险/信誉）。
3. 把所有工作映射到“主/次/无关”，无关的直接砍。

## 02 思维骨架（40%）

### 论证链

1. 阶段变化会改变主次矛盾与资源策略。
2. 任务爆炸的解法是明确主任务与底线。
3. 扩大联盟必须与自身能力建设并行，否则联盟会失控或变成空壳。
4. 群众基础（当代：用户/客户/一线支持）决定续航与主动权。

### 误区

- 只做对外不做内功：合作越多越乱。
- 只做内功不抓主任务：体系很好但错过窗口。

## 03 知识图鉴（60%）

### 模板：阶段任务一页纸

- 阶段：保命/相持/反攻（或你自己的阶段命名）
- 主任务：……
- 胜负指标：……
- 次任务（3 条以内）：……
- 底线（3 条）：……
- 节奏：两周冲刺点/两周固化点

### 文本图：任务收敛

```text
任务爆炸 -> 主任务/次任务/无关 -> 资源集中 -> 交付证据 -> 扩盟与能力建设同步
```

## 04 底层解码（80%）

### 关键约束

- 协作越多，复杂性越高，必须用规则降低协作成本。
- 外部窗口短，内部建设慢，需要节奏化推进。

## 05 认知破局（100%）

### 模型A：任务收敛矩阵

- 输入：所有任务清单
- 步骤：映射到主/次/无关 → 无关砍掉 → 次任务只保留能支持主任务的 3 条 → 为主任务设里程碑
- 校验：两周内主任务是否产出可展示证据
- 止损：证据不出 → 继续砍任务直到可交付

### 模型B：扩盟×内功双轨

- 输入：一个联盟合作方向
- 步骤：外轨跑通一个标杆合作 → 内轨固化 SOP（条款/交付/风控）→ 复制扩张
- 校验：合作可复制且交付不崩
- 止损：合作带来内耗/成本失控 → 收缩并先固化规则

### 六场景推演

- 职场：重组后先定主任务与底线；原则：任务收敛。
- 创业：窗口期双轨推进；原则：标杆先行，SOP 再复制。
- 人生：阶段转换先稳底盘；原则：底线优先。
- 人际：复杂关系先定共同目标与边界；原则：规则先于情绪。
- 家庭：家庭任务爆炸时先收敛；原则：主任务明确。
- 教育：把学习任务变成阶段任务；原则：小闭环可复盘。

### 复盘模板

- 主任务：是否推进？证据？
- 次任务：是否过载？砍了什么？
- 底线：是否触线？原因？
- SOP：本轮固化了什么？
- 下轮：冲刺点与固化点

### 练习题

1. 把你当前任务清单做一次“主/次/无关”分类并砍掉 30%。
2. 写一个阶段任务一页纸，并设两周内必须产出的证据。
3. 写出三条底线，并给出触线时的止损动作。
