# 《星星之火，可以燎原》｜逆风增长引擎（Small Win → Scale）

一句硬核结论：判断一个方向值不值得押注，不看情绪与热闹，看它能否形成“可复制的小胜利”，并沿着据点链滚动扩张。

## 01 局势快照（20%）

### 历史坐标

- 写作时间：1930-01-05
- 处境：逆风、资源弱、外界唱衰，核心任务是建立信心与可复制路径。
- 时间线（事件）：
  - 1927-04-12：四一二政变爆发，革命遭遇重大挫折，进入艰难重建期。
  - 1927-09-09：秋收起义爆发，形成以农村为依托的斗争道路。
  - 1928-04-28：井冈山会师，开始在根据地实践中积累“组织—供给—群众”的系统经验。
  - 1929-12-28：古田会议召开，明确政治工作与组织建设路线，为后续扩张提供制度底座。
  - 1930-01-05：以书信形式回应悲观估计，强调“星火—据点—燎原”的可验证路径。
  - 1930-05：围绕“调查研究/反教条”的方法论进一步展开（同卷相关篇目）。
- 资料来源：
  - https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-19300105.htm

### 金句与摘录

- “星星之火，可以燎原。”
- “我们看事情必须要看它的实质，而把它的现象只看作入门的向导，一进了门就要抓住它的实质，这才是可靠的科学的分析方法。”
- “如果把革命的主观力量看小了，把反革命力量看大了，这也是一种不切当的估量。”
- “中国是全国都布满了干柴，很快就会燃成烈火。”
- “分兵以发动群众，集中以应付敌人。”
- “敌进我退，敌驻我扰，敌疲我打，敌退我追。”
- “固定区域的割据，用波浪式的推进政策。”
- “只有积极的口号积极的态度才能领导群众。”

### 核心思想（可调用要点）

- 用“实质分析”替代“表象恐慌”：区分局部挫折与总体趋势，避免把短期环境一般化。
- 把信心建立在证据上：用可复制的小胜利与据点链扩张，替代口号与情绪。
- 把增长写成战术：先集中赢一个节点，再分兵发动更大范围的参与与反馈。
- 用节奏对抗不确定：波浪式推进、盘旋式打圈子，避免一次性豪赌。
- 把路线与组织绑在一起：没有组织化与群众基础，任何“乐观”都不可落地。

### 核心问题

当环境不支持时，如何证明方向正确，并把小胜利扩成大势？

### 现代映射

- 创业：冷启动与逆风增长
- 职场：边缘团队/新业务线的上升路径
- 人生：从低谷重建能力曲线

### 长案例（沉浸式）

你做一个新产品，拉新贵、留存差、内部不看好。你不再争论宏大叙事，而是选一个最小可跑通的场景：一个细分人群、一个刚需频次、一个可交付闭环。你把“星星”做成：复购率、转介绍、口碑证据。然后复制到相邻人群，扩渠道，扩供给。半年后，别人说你“突然起来”，其实你一直在滚雪球。

### 关键概念

- 星星：最小可复制胜利（指标稳定、成本可控、可复现）
- 燎原：据点链扩张（一个场景跑通后复制到邻近场景）
- 节奏：扩张与固化交替，避免扩张过早导致崩盘

### 可操作结论

1. 把方向改写成“最小胜利定义”：一条指标 + 一条时间窗 + 一条成本上限。
2. 先做一个可复现样板间，再谈规模化。
3. 每次扩张只改一个变量（人群/渠道/供给其一）。

## 02 思维骨架（40%）

### 论证链

1. 逆风时宏大叙事无用，证据与小胜利才有用。
2. 小胜利必须可复制，否则只是运气。
3. 扩张必须沿据点链推进，不能跳跃式扩张。
4. 节奏决定生死：扩张过早会让供给线断裂。

### 误区

- 把“曝光”当燎原：热闹但不可复制。
- 把“扩张”当证明：规模越大死得越快。

## 03 知识图鉴（60%）

### 清单：小胜利三条件

1) 指标稳定（非一次性噪声）  
2) 成本可控（单位经济成立）  
3) 可复现（换人/换周仍成立）  

### 文本图：据点链扩张

```text
场景A跑通 -> 固化流程 -> 复制到场景B -> 扩渠道 -> 扩供给 -> 新据点
```

## 04 底层解码（80%）

### 关键约束

- 逆风时资源稀缺，必须把失败成本压到最小。
- 证明不是说服别人，而是建立可复验事实。

## 05 认知破局（100%）

### 模型A：最小胜利定义（MSD）

- 输入：方向/目标
- 步骤：选 1 个细分人群 → 选 1 个刚需场景 → 定 1 条指标与时间窗 → 设成本上限
- 校验：两周内能否复现 2 次
- 止损：无法复现 → 换场景或换价值主张

### 模型B：据点链复制

- 输入：已跑通的小胜利
- 步骤：固化 SOP → 复制到邻近场景 → 只改一个变量 → 复盘
- 校验：单位经济不崩、交付不崩
- 止损：供给线吃紧/质量下降 → 先固化再扩张

### 六场景推演

- 职场：用小胜利拿资源；风险：只汇报不产证据；原则：指标可复现。
- 创业：先跑通一条价值链；风险：盲目扩张；原则：据点链推进。
- 人生：先重建一个能力闭环；风险：多线拉扯；原则：一轮一小胜。
- 人际：先建立一条可持续交换；原则：可复制的边界。
- 家庭：先改善一个高频摩擦点；原则：小改动可复验。
- 教育：先让孩子体验一次阶段成果；原则：先成就再加码。

### 复盘模板

- 本轮星星：指标/成本/时间窗
- 复现证据：第 1 次/第 2 次
- 固化动作：流程/模板/角色分工
- 下一步扩张：只改哪个变量

### 练习题

1. 为你的项目写一个 MSD，并设两周复现目标。
2. 选一个邻近场景做复制实验，只改一个变量。
3. 写出你最可能扩张过早的信号，并设止损阈值。
