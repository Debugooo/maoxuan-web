# 毛选内容库约定

## 文件命名

- 单篇文档：`《篇名》.md`
- 索引文档：`index.md`

## 单篇 frontmatter（必填）

- slug: URL 友好标识（建议用拼音或英文短语）
- title: 篇名（含书名号）
- volume: 卷信息（未知可填 1-4 或留空字符串）
- core_level: S / A / B
- tags: 方法论标签（矛盾/实践/调查/组织/战略/战术/资源/复盘 等）
- scenarios: 现代场景适配度（high/medium/low）

## 单篇正文结构（必填）

每篇必须包含以下 5 个一级标题（完全一致，用于自动校验与索引）：

- 01 局势快照（20%）
- 02 思维骨架（40%）
- 03 知识图鉴（60%）
- 04 底层解码（80%）
- 05 认知破局（100%）

其中 05 必须包含：

- 可调用模型（输入→判断→动作→校验）
- 六场景推演（职场/创业/抉择/人际/家庭/教育）
- 复盘模板
- 研讨练习题
