# 《中国社会各阶级的分析》｜人群结构雷达（People → Interests）

一句硬核结论：先把“谁和谁站一起、谁会在关键时刻倒向哪边”画清楚，否则你所有策略都是对空气挥拳。

## 01 局势快照（20%）

导语：你以为自己在做业务/谈合作/搞关系，其实你在处理利益结构。《阶级分析》提供一个更通用的现代版本：把人群拆成不同的利益位置、风险承受、信息来源与行动能力，然后判断“谁能被动员、谁只会观望、谁会阻挠”。它不是贴标签，而是为了降低战略误判：你不能用同一套话术面对不同激励的人。

### 历史坐标

- 写作时间：1925-12-01
- 写作任务：在组织需要扩张与动员时，先把“盟友/中立/对手”的结构画出来。
- 压力来源：资源稀缺、队伍弱、需要找到可持续的群众基础与统一战线边界。
- 时间线（事件）：
  - 1924-01-20：国民党一大召开，国共合作与群众动员进入新阶段。
  - 1925-03-12：孙中山逝世，国民党内部路线分化加速。
  - 1925-05-30：五卅惨案爆发，反帝群众运动高涨。
  - 1925-06-19：省港大罢工开始，城市工运与社会动员能力跃迁。
  - 1926-07-09：北伐战争开始，革命与反革命力量重新洗牌。
  - 1927-04-12：四一二政变，资产阶级与革命阵营分化被“实证”。
- 资料来源：
  - https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-19251201.htm

### 核心思想（可调用要点）

- 先定义任务：你要完成的阶段目标是什么（动员/夺取/防守/联合）。
- 再做结构：把人群按“经济位置→利益/风险→态度→可动员性”拆开。
- 敌友判定优先于话术：先判阵营与边界，再谈策略与叙事。
- 中间层是变量：给出能让其“下注”的确定性与安全感，避免把它当铁盟或铁敌。
- 领导权与同盟军同时管理：联合可联合者，但不交出主导权与组织能力。
- 把“道德标签”降级为噪声：用可观察的激励与行为替代情绪判断。
- 行动校验：每次动员必须出现可观察信号（公开站队、资源投入、二级传播）。

### 博弈版图

- 玩家不是“好人/坏人”，而是不同激励位置：
  - 既得利益者：更怕变化，倾向维持秩序。
  - 机会型中间层：看风向，收益确定才下注。
  - 受压者/被忽视者：愿意变，但需要路径与组织。
- 决胜点：谁掌握信息与组织能力，谁就能把“松散诉求”转成“可执行的集体行动”。

### 核心问题

用什么标准快速判断：某个群体会成为盟友、观望者还是阻力？以及你该投入哪类动员成本？

### 现代映射

- 职场：关键不是“同事友不友好”，而是“对方的 KPI、晋升路径、风险承受”。
- 创业：客户、渠道、投资人、供应链、核心员工，是不同“阶级位置”，不能用同一套故事。
- 人际：关系不是情绪，是交换与边界；对方的“资源/风险/面子”决定行为。
- 教育：孩子/家长/学校/同伴也是结构；只盯“孩子态度”会错过系统变量。

### 长案例（沉浸式）

你准备在公司推动一个跨部门“成本治理”项目。你以为只要把方案讲清楚就行，结果反对声音此起彼伏：财务支持你，但业务线暗中抵制；中层嘴上同意，回去不动；少数骨干主动帮你，却被边缘化。你这才发现：你面对的不是“意见分歧”，而是利益结构——有些人靠“预算规模”证明价值，有些人靠“短期业绩”保命，有些人靠“流程控制”攫取权力。你需要的是一张“人群结构雷达”：谁是天然盟友（收益与项目一致），谁是可争取中间层（风险可控+收益可见），谁是结构性阻力（收益被削弱）。否则你会把资源耗在说服不可说服的人身上。

### 关键概念（最小定义）

- 位置：一个人在系统里靠什么获益、靠什么避险。
- 激励：推动行为的真实奖励与惩罚（不是口号）。
- 动员成本：把一个人从“知道”推到“行动”所需的资源（承诺、时间、风险、组织支持）。
- 中间层：会随风向移动的人群；争取他们靠“确定性与安全感”。
- 统一战线：在阶段目标下与部分力量结盟，但不放弃主导权与边界。

### 可操作结论（48 小时可动手）

1. 写一张“利益结构表”：列出关键人/群体，分别填 KPI/收益/风险/信息源/行动能力。
2. 对每个群体给出策略：争取（交换）/稳住（安全）/隔离（边界）。
3. 先打“可转化的中间层”：用一个可验证的小胜利改变风向。

## 02 思维骨架（40%）

导语：这篇的骨架不是“把人分成几类”，而是一个战略流程：先定义阶段目标，再画利益结构，再决定动员路径与边界，最后用结果校验是否站队正确。

### 全文论证链（可转译为决策链）

1. 社会结构不是平均的，不同位置有不同利益与恐惧。
2. 行为由利益位置决定，话术只能影响边缘，不改变结构。
3. 要完成阶段任务，必须识别可以联合的力量与必须对抗的力量。
4. 中间层是关键变量：风向改变会导致他们转化。
5. 动员不是情绪号召，而是组织能力：让行动成本下降、风险可控。
6. 站队与边界必须清晰：不然会被对手用“混合联盟”反向瓦解。

### 反面模式（当代常见误区）

- 把“人品”当结构：用道德评判替代利益分析，导致策略漂浮。
- 把“说服”当动员：用 PPT 代替交换与保障，结果行动不发生。

### 落地流程（输入→判断→动作→校验→止损）

```text
阶段目标 -> 关键人群清单 -> 利益/风险/能力画像 -> 三类策略(争取/稳住/隔离)
  -> 先打一个可验证小胜利 -> 风向观察(中间层是否移动) -> 扩大战果或换路径
```

### 工具 2：中间层转化判据（4 条）

1. 他是否愿意把“口头支持”升级成“公开站台”？
2. 他是否愿意承担一次小风险（试点/背书/资源倾斜）？
3. 他是否愿意在关键会议上改变发言立场？
4. 他是否开始主动拉人加入（出现二级传播）？

### 术语对照

- 阶级分析 → 利益结构分析
- 群众路线 → 从一线事实出发的动员与反馈机制
- 统一战线 → 阶段性联盟管理（交换、边界、主导权）

## 04 底层解码（80%）

### 写作处境的关键约束

- 资源不足：不能同时对所有人做工作。
- 信息不对称：口号多、真实激励隐藏，需要结构化判断。
- 风险巨大：站错队会导致组织被孤立、行动成本指数级上升。

### 当代等价约束（适用/失效）

- 适用：跨部门项目、商业合作、组织变革、社区动员等“多方激励冲突”场景。
- 失效：单人纯技术问题（无利益冲突）——这时结构分析是过度工程。

### 决策逻辑（杠杆点与信号）

- 杠杆点：改变中间层的风险-收益比（让他们“敢站、敢动、敢扩散”）。
- 信号：当中间层开始公开背书、愿意承担试点风险，风向在变。

## 05 认知破局（100%）

### 可调用模型

**模型A：利益结构三分法（争取/稳住/隔离）**

- 输入：阶段目标、关键人群名单
- 步骤：
  1. 对每个群体写“收益/损失/风险承受/行动能力”
  2. 判定策略：争取（可交换）、稳住（给安全）、隔离（设边界）
  3. 为“争取对象”设计一条交换（资源/荣誉/路径）
- 校验：被争取对象是否出现公开动作（背书/资源倾斜/拉人）
- 止损：连续两轮无动作 → 降级为稳住或隔离

**模型B：中间层转化小胜利（48h 试点）**

- 输入：一个可试点的小场景、一个可观测指标
- 步骤：选 1 个低风险试点 → 产出 1 个硬证据 → 公开展示 → 邀请中间层共同署名
- 校验：二级传播是否出现（非你团队的人开始复述你的故事）
- 止损：证据无法产生 → 缩小试点范围或换指标

### 六场景推演

- 职场内卷：先找天然盟友（收益一致）→ 做试点出成果 → 争取中间层公开站台；风险：别先去硬碰结构性阻力。
- 创业困境：把客户/渠道/投资人拆开画像 → 每次只争取一个关键节点；风险：别用同一套故事打所有人。
- 人生抉择：识别“你真正被谁影响”（评价者/资源提供者/你自己）→ 设边界；风险：把情绪当结构。
- 人际交往：先看交换与边界 → 再谈理解；风险：用道德评判替代规则设计。
- 家庭生活：把冲突拆成分工/规则/节奏 → 找可执行的小调整；风险：用“讲道理”压过结构问题。
- 家庭教育：识别孩子的激励（成就/归属/掌控）→ 设计低风险试验；风险：只靠说服、不改环境。

### 复盘模板（一页纸）

- 目标：本阶段要赢什么？
- 人群结构：天然盟友/中间层/阻力各是谁？
- 动作：48h 试点做了什么？
- 证据：出现了哪些可观察变化？
- 风向：中间层是否移动？表现是什么？
- 下一步：争取/稳住/隔离策略是否需要调整？

### 研讨练习题

1. 写出你当前处境的三类人群，并各自填“收益/损失/风险承受”。
2. 选一个中间层对象，设计一个 48 小时可完成的“可见小胜利”试点。
3. 如果你必须与某个阻力共存，你的边界条款应该是什么？
