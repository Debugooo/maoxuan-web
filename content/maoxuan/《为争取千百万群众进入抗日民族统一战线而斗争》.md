# 《为争取千百万群众进入抗日民族统一战线而斗争》｜动员转化漏斗（Support → Participation）

一句硬核结论：力量不来自“同意你”，来自“参与你”；动员要像做增长一样设计入口、路径、激励与组织化机制。

## 01 局势快照（20%）

### 历史坐标

- 写作时间：1937-05-08
- 写作任务：对《中国共产党在抗日时期的任务》报告的讨论作结论，核心落点是“把方针变成群众方针”，把统一战线从上层共识推进到群众参与。
- 时间线（事件）：
  - 1935-12-09：一二九运动爆发，救亡动员成为全国性浪潮。
  - 1936-12-12：西安事变爆发，国内和平与统一战线条件加速形成。
  - 1937-05-03：提出抗日时期任务与民主问题，形成阶段路线框架。
  - 1937-05-08：作结论，强调“争取民主—巩固和平—实现抗战”与干部建设。
  - 1937-07-07：全面抗战爆发，动员与组织化进入更大规模兑现期。
- 资料来源：
  - https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-19370508.htm

### 金句与摘录

- “我们说和平取得了，并不是说和平巩固了，相反，我们说它是不巩固的。”
- “为什么提出‘巩固和平’、‘争取民主’、‘实现抗战’这样三位一体的口号？”
- “共产党有本领把革命逐步地推向前进，但没有本领把全国的坏事在一个早晨去掉干净。”
- “民主是抗日的保证，抗日能给予民主运动发展以有利条件。”
- “今天的联合资产阶级抗日派，正是走向社会主义的必经的桥梁。”
- “这些干部和领袖……富于牺牲精神，能独立解决问题，在困难中不动摇。”
- “干部决定一切。”
- “把党的方针变为群众的方针，还须要我们长期坚持的、百折不挠的……努力。”

### 核心思想（可调用要点）

- 动员不等于宣传：宣传解决认知，组织化解决参与与持续行动。
- 三件套推进：巩固和平（减少内耗）→争取民主（扩大参与通道）→实现抗战（聚焦外部目标）。
- 把参与设计成路径：入口、任务、反馈、激励、节奏，缺一项就会“同意多、参与少”。
- 干部是转化引擎：需要大量能独立解决问题、能带队伍的中层骨干把方针落到现场。
- 允许波折但不允许停顿：承认“不能一夜清除坏事”，但必须用持续努力把车轮推向前。

### 核心问题

为什么很多运动/项目/组织“声势大、参与少”？因为你只做了宣传，没有做转化与组织化。

### 现代映射

- 创业：从关注到付费再到复购与转介绍
- 职场：从认同到协作再到共同交付
- 教育：从“知道重要”到“持续行动”

### 长案例（沉浸式）

你要推动一个跨部门治理项目，所有人都说“很重要”，但没人出人、没人担责。你把动员改成漏斗：先让大家看到一个可复验的小成果（认知），再提供低门槛参与方式（参与），再把参与者组织成小组与规则（组织化），最后让他们产出结果并获得奖励（激励）。一个月后，项目从口号变成机制。

### 关键概念

- 动员：把人从旁观者变成参与者的过程。
- 转化路径：入口→任务→反馈→激励→复盘。
- 组织化：分工、规则、代表机制、持续协作。

### 可操作结论

1. 设计 3 个参与入口（低/中/高门槛）。
2. 为每个入口配“任务卡”（10 分钟就能开始）。
3. 把参与者组织成小组与节奏（每周一次小交付）。

## 02 思维骨架（40%）

### 论证链

1. 统一战线需要群众参与，否则只是上层协议。
2. 参与要降低门槛并提供可见收益。
3. 宣传解决认知，组织化解决持续行动。
4. 规模来自复制：可复用的入口与任务卡。

### 误区

- 只喊口号不设计入口
- 只拉人不做组织化（结果很快流失）

## 03 知识图鉴（60%）

### 模板：动员漏斗（3 层入口）

- L1 低门槛：转发/签名/加入群/一次小任务
- L2 中门槛：参与一次讨论/提供一次材料/完成一项任务
- L3 高门槛：承担角色/负责小组/持续交付

### 文本图：从支持到参与

```text
认同(宣传) -> 入口(低门槛) -> 任务卡(可执行) -> 组织化(小组/规则) -> 交付(证据) -> 扩散
```

## 04 底层解码（80%）

### 关键约束

- 参与成本高于认同成本，必须降低门槛与提供反馈。
- 规模化需要可复制机制，否则只能靠领导个人动员。

## 05 认知破局（100%）

### 模型A：三入口动员设计

- 输入：目标与目标人群
- 步骤：设计 L1/L2/L3 三层入口 → 为每层写任务卡 → 建反馈机制（当天反馈）
- 校验：L1→L2→L3 转化是否增长
- 止损：转化不动 → 降低门槛或提高收益可见性

### 模型B：组织化节奏（周循环）

- 输入：参与者名单
- 步骤：分小组 → 定每周小交付 → 公示结果 → 奖励与升级路径
- 校验：持续参与率、交付数量
- 止损：内耗上升 → 收缩小组规模并简化规则

### 六场景推演

- 创业：关注→试用→付费→复购→转介绍；原则：入口与任务卡可复制。
- 职场：认同→参与→承担→交付；原则：反馈要快、收益要可见。
- 人生：知道→做一次→做两周→固化习惯；原则：低门槛启动。
- 人际：共识→共同行动→共同规则；原则：组织化减少失约。
- 家庭：口头承诺→分工任务卡→每周复盘；原则：用节奏保持参与。
- 教育：学习认同→每日小任务→周复盘；原则：可见进步带来持续。

### 复盘模板

- 入口：L1/L2/L3 各是什么？
- 任务卡：最有效的是哪一张？
- 转化：哪个环节流失最大？
- 组织化：小组与规则是否过重？
- 下轮：降低门槛/增加反馈/调整激励

### 练习题

1. 为你的项目设计三层入口与三张任务卡。
2. 写一个“当天反馈机制”，保证参与者 24 小时内得到反馈。
3. 设计一个周循环节奏，让参与从一次性变成持续行动。
