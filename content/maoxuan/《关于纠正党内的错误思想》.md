# 《关于纠正党内的错误思想》｜组织免疫系统（Org → Immunity）

一句硬核结论：团队崩不是因为不努力，而是错误思维模式在扩散；要像修 BUG 一样修组织：定位症状、找根因、设机制。

## 01 局势快照（20%）

### 历史坐标

- 写作时间：1929-12（通行版本仅标到月份；古田会议召开于 1929-12-28）
- 任务：把松散队伍变成能打仗的组织，需要纠正一组常见的组织性偏差。
- 写作方式：不是道德批评，而是“症状—危害—纠偏”。
- 时间线（事件）：
  - 1927-08-01：南昌起义，人民军队创建，政治工作与组织建设问题随之提出。
  - 1927-09-09：秋收起义爆发，转入以农村为依托的长期斗争形态。
  - 1928-04-28：井冈山会师，队伍扩大与成分复杂化，组织治理难度上升。
  - 1928-11-25：形成一批关于“群众、党、红军、供给”的经验总结（与边界斗争相关）。
  - 1929-12-28：红四军第九次党代会（古田会议）召开，系统整顿党内与军内路线。
  - 1930-01-05：围绕“路线与前途”争论持续，需要把政治判断与组织执行再度拉齐。
- 资料来源：
  - https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-192912.htm

### 金句与摘录

- “红军决不是单纯地打仗的，它除了打仗消灭敌人军事力量之外，还要负担宣传群众、组织群众、武装群众、帮助群众建立革命政权以至于建立共产党的组织等项重大的任务。”
- “红军的打仗，不是单纯地为了打仗而打仗，而是为了宣传群众、组织群众、武装群众，并帮助群众建设革命政权才去打仗的……也就是失去了红军存在的意义。”
- “党对于军事工作要有积极的注意和讨论。一切工作，在党的讨论和决议之后，再经过群众去执行。”
- “极端民主化的危险，在于损伤以至完全破坏党的组织，削弱以至完全毁灭党的战斗力。”
- “党的各级机关解决问题，不要太随便。一成决议，就须坚决执行。”
- “党的纪律之一是少数服从多数。”
- “党内批评是坚强党的组织、增加党的战斗力的武器。”
- “离开了实际情况的调查，就要堕入空想和盲动的深坑。”
- “主观主义……其必然的结果，不是机会主义，就是盲动主义。”

### 核心思想（可调用要点）

- 把军队/团队定义清楚：它不是“只完成任务的工具”，而是“带着政治/组织目标的行动系统”。
- 用“症状—来源—纠正方法”替代人格批评：先描述可观察行为，再对准机制根因。
- 将决议变成执行：讨论产生统一口径；决议一旦形成，必须进入坚决执行与反馈循环。
- 管好两类危险：只讲军事不讲政治（目的漂移）与极端民主化（组织瓦解）。
- 批评机制要保留：批评用于增强战斗力与纠错，不用于个人攻击与报复。
- 调查研究是反主观主义的底座：用事实材料决定策略与工作方法。

### 博弈版图

- 外部不确定性要求组织高度一致与可执行。
- 内部偏差会把组织拉回到“个人主义/山头/短视/逃避责任”。

### 核心问题

如何把组织问题从“人格批评”转成“机制纠偏”？

### 现代映射

- 职场：协作失败常源于目标不一致、责任不清、指标口径混乱。
- 创业：最致命不是缺资源，而是内部互不信任、各自为战。

### 长案例（沉浸式）

你带一个小团队，开始时大家很拼，但三个月后出现：有人只挑容易的活、有人抢功、有人甩锅、有人私下拉小群。你试图靠“打鸡血”和“谈理想”解决，结果更糟。你改用免疫系统思路：把症状列出来，逐一对应机制：目标对齐、责任边界、透明度、奖惩、复盘。两周后，协作摩擦显著下降。

### 关键概念

- 错误思想模式：可重复出现、可传播的认知偏差与行为习惯。
- 组织免疫：发现偏差—隔离扩散—修复机制—复盘升级的闭环。

### 可操作结论

1. 把团队摩擦写成“症状清单”（不写人名）。
2. 对每个症状写“机制根因”（激励/流程/信息/权责）。
3. 一次只修一个根因，用两周验证。

## 02 思维骨架（40%）

### 论证链

1. 组织的敌人之一是内部偏差扩散。
2. 偏差常伪装成“能力/性格”，实为激励与规则问题。
3. 纠偏要靠制度与训练，不靠情绪与喊话。
4. 纪律不是压人，是降低协作成本与不确定性。

### 误区

- 把批评当治理：开会骂人但不改机制。
- 把忍耐当团结：不处理扩散源，最后全员感染。

### 落地流程

```text
症状(行为) -> 根因(机制) -> 最小规则 -> 执行与反馈 -> 复盘与升级
```

## 03 知识图鉴（60%）

### 清单：组织偏差快速诊断（示例）

- 个人英雄主义：只认个人能力，不认流程与协作
- 山头主义：信息与资源在小圈子内流转
- 机会主义：遇强就退、遇弱就硬，目标随风摆
- 形式主义：报告很多、证据很少

### 模板：机制根因四问

1) 这个行为被什么奖励？  
2) 它在规避什么惩罚？  
3) 信息在哪一层断掉？  
4) 权责边界哪里模糊？  

## 04 底层解码（80%）

### 关键约束

- 小组织在压力下，任何偏差都会被放大。
- 没有纪律与透明度，协作成本指数级上升。

### 适用/失效

- 适用：0–50 人团队、跨部门项目、快速迭代组织。
- 失效：纯个人任务（无需组织协作）时，机制治理过度。

## 05 认知破局（100%）

### 模型A：组织免疫闭环（两周一轮）

- 输入：症状清单
- 步骤：选 Top1 症状 → 写机制根因 → 制定最小规则（1–3 条）→ 两周执行 → 复盘
- 校验：协作摩擦是否下降（返工/扯皮/卡点次数）
- 止损：规则无法执行 → 回到权责与激励重写

### 模型B：纪律最小集

- 输入：当前最耗散的协作点
- 步骤：定义交付口径 → 定义责任人 → 定义升级路径 → 定义止损阈值
- 校验：升级是否更少、交付是否更稳
- 止损：执行成本过高 → 缩减规则到最小集

### 六场景推演

- 职场：写症状→写机制→两周试点规则；风险：只骂人不改系统；原则：机制优先。
- 创业：先统一胜负指标→再谈价值观；风险：山头化；原则：透明度与纪律降损耗。
- 人生：把拖延当症状，找机制根因（环境/奖励）；原则：用规则替代意志力。
- 人际：把冲突写成边界问题；原则：规则化沟通。
- 家庭：分工不清是机制问题；原则：写成可执行条款。
- 教育：学习行为靠环境与反馈；原则：建立小闭环复盘。

### 复盘模板

- 本轮症状：Top1 是什么？
- 根因：被什么奖励/惩罚？
- 新规则：1–3 条
- 执行证据：发生了什么变化？
- 下一轮：保留/调整/止损

### 练习题

1. 写出你团队的 5 个症状，并选 Top1 做两周试点。
2. 为 Top1 症状写出“机制根因四问”的答案。
3. 把一条规则写到可执行（责任人/口径/升级/止损）。
