# 《怎样分析农村阶级》｜分层决策引擎（Segment → Act）

一句硬核结论：所有“搞不定的人群”，本质是你没做有效分层；分层不是名词游戏，是为了让策略、资源与行动可落地。

## 01 局势快照（20%）

### 历史坐标

- 写作时间：1933-10（通行版本仅标到月份）
- 写作任务：为纠正土地改革中的偏向，给出“按生产资料占有、劳动参与与剥削方式”划分阶级成分的可操作标准。
- 时间线（事件）：
  - 1931-12-01：《中华苏维埃共和国土地法》公布（文库注释提及），土地改革进入制度化阶段。
  - 1933-06-01：查田运动训令发布（相关文库注释提及），要求清查阶级成分与土地关系。
  - 1933-10：撰写《怎样分析农村阶级》，作为划分农村阶级成分的标准文件。
  - 1934-01-22：第二次全国工农兵代表大会在瑞金召开（同卷相关文献背景），政策体系进一步统一。
  - 1934-01-27：提出“关心群众生活、注意工作方法”，强调政策落地要回到群众利益与方法。
- 资料来源：
  - https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-193310.htm

### 金句与摘录

- “占有土地，自己不劳动，或只有附带的劳动，而靠剥削农民为生的，叫做地主。”
- “地主剥削的方式，主要地是收取地租。”
- “富农一般都占有比较优裕的生产工具和活动资本，自己参加劳动，但经常地依靠剥削为其生活来源的一部或大部。”
- “富农的剥削方式，主要是剥削雇佣劳动（请长工）。”
- “中农的生活来源全靠自己劳动，或主要靠自己劳动。”
- “贫农一般都须租入土地来耕，受人地租、债利和小部分雇佣劳动的剥削。”
- “贫农一般要出卖小部分的劳动力，这是区别中农和贫农的主要标准。”
- “工人（雇农在内）一般全无土地和工具……完全地或主要地以出卖劳动力为生。”

### 核心思想（可调用要点）

- 分层先看“收入来源”：靠劳动、靠地租、靠债利、靠雇工剥削，各自对应不同策略。
- 指标必须可观察：土地占有、是否雇工、是否出租、是否放债、是否出卖劳动力。
- 分层的目的在资源配置：对不同层用不同政策包，避免“一刀切”造成执行偏差。
- 以边界防误伤：用“主要生活来源/经常性”区分临时现象与结构性成分。
- 复盘口径一致：所有团队用同一套标准，减少争议与内耗，让行动能规模化复制。

### 核心问题

面对复杂人群，如何用可观察指标做分层，并据此决定策略？

### 现代映射

- 创业：用户分层、客户分层、渠道分层
- 职场：团队成员分层（能力/动机/风险/影响力）

### 长案例（沉浸式）

你做 B2B，销售说“客户都一样难搞”。你把客户按付费能力、决策链条、交付复杂度、续费概率分层，发现资源应该集中在“高续费+低交付成本”的层，而不是在“高客单但交付吞噬”的层。团队从“到处救火”变成“有结构的增长”。

### 关键概念

- 分层指标：必须可观察、可复验（不能是感觉）。
- 策略差异：不同层用不同策略（获客/交付/服务/风险）。

### 可操作结论

1. 选 3–5 个可观察指标做分层（付费、频次、交付成本、影响力等）。
2. 为每一层写“策略包”：目标、动作、风险、止损。
3. 每月复盘一次分层是否需要更新。

## 02 思维骨架（40%）

### 论证链

1. 人群差异决定策略差异。
2. 分层必须基于事实指标，不可基于偏见。
3. 分层的目的在于资源配置与策略选择。

### 误区

- 用标签代替指标
- 分层后策略仍一刀切

## 03 知识图鉴（60%）

### 模板：分层指标选择（示例）

- 收益维度：LTV/复购/续费
- 成本维度：交付成本/服务成本
- 风险维度：违约/投诉/波动
- 影响维度：带来转介绍/标杆效应

### 文本图：分层→策略

```text
指标 -> 分层 -> 策略包 -> 执行 -> 复盘(分层更新)
```

## 04 底层解码（80%）

### 关键约束

- 资源有限，必须把资源投给最能改变结构的层。
- 分层会随环境变化，必须动态更新。

## 05 认知破局（100%）

### 模型A：3×3 分层矩阵

- 输入：人群列表
- 步骤：选 1 个收益指标 + 1 个成本指标 → 形成 3×3 矩阵 → 为每格写策略包
- 校验：资源是否更集中、返工是否更少
- 止损：指标不稳定 → 换指标口径

### 模型B：策略包（每层一页纸）

- 输入：某一层定义
- 步骤：目标→动作→风险→止损→负责人→验收证据
- 校验：该层的结果是否改善
- 止损：连续两轮无改善 → 调整层定义或退出该层

### 六场景推演

- 职场：把成员按“能力×动机”分层，配不同任务与辅导；原则：不同层不同打法。
- 创业：客户按“LTV×交付成本”分层；原则：先打高性价比层。
- 人生：把目标按“收益×风险”分层；原则：先做低风险高收益试验。
- 人际：关系按“信任×交换”分层；原则：边界不同。
- 家庭：任务按“重要×紧急”分层；原则：资源优先级清晰。
- 教育：孩子任务按“能力×兴趣”分层；原则：先建立正反馈层。

### 复盘模板

- 分层指标：选了什么？证据？
- 资源分配：各层投入比例？
- 结果：哪层带来最大收益/最大漏点？
- 更新：下月层定义/策略包怎么改？

### 练习题

1. 为你的用户/客户做一个 3×3 分层矩阵。
2. 写出最高优先层的“策略包一页纸”。
3. 为最低优先层写退出条件（止损）。
