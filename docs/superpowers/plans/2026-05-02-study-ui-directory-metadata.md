# 研读系统目录页改版 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 改造研读系统 `/study` 与分卷目录页，使目录条目默认点标题进指南、右侧仅保留原文按钮，并为四卷全量条目补齐“时间 + 一句话主题 + 5 标签”以支撑后续知识图谱。

**Architecture:** 保持现有内容系统（`content/maoxuan-*/**/*.md` + `content/maoxuan-cos/index.json`）为单一数据源；目录页仍以 `VOLUMES` 的分期分组展示“原书顺序”，并通过 querystring `?tab=learning|book` 切换。v2–v4 先自动生成“空白指南页 + 原文占位页（含外链）”，确保站内可导航并通过 `validate:study`。

**Tech Stack:** Next.js App Router、TypeScript、Tailwind、Markdown（react-markdown + remark-gfm）、gray-matter 校验脚本

### Task 4: v2–v4 全量条目接入 index.json（并生成空白指南/原文占位）

**Files:**
- Modify: [index.json](file:///workspace/content/maoxuan-cos/index.json)
- Create: `scripts/generate-study-placeholders.mjs`
- Create (generated by script):
  - `content/maoxuan-guides/v2/*.md`
  - `content/maoxuan-guides/v3/*.md`
  - `content/maoxuan-guides/v4/*.md`
  - `content/maoxuan-original/v2/*.md`
  - `content/maoxuan-original/v3/*.md`
  - `content/maoxuan-original/v4/*.md`

- [ ] **Step 1: 定义 v2–v4 的稳定 id 规则**

规则：从 `source_url` 里抽取 `mao-<code>.htm` 的 `<code>`，生成：
`mx-<volume>-<code>`
例：`...mao-19370723.htm` → `mx-v2-19370723`

- [ ] **Step 2: 写生成脚本（不手工逐个建文件）**

脚本职责：
- 读取 `src/lib/study/volumes.ts`（通过解析导出的 JSON-like 结构，或维护一份简化列表）拿到 v2–v4 的 `title/source_url`
- 生成/更新 `content/maoxuan-cos/index.json`：
  - 将 v2–v4 的 `volumes.v2.items/v3.items/v4.items` 填满
  - 为每条写入：`id/volume/title/source_url/guide_path/original_path/date/topic/concepts(5)`
  - `learningOrder` 保持当前 v1 不变；v2–v4 可暂不加入（目录页仍可用 tab 展示）
- 为每条生成对应 md：
  - guide：包含固定 `## 1–## 10` H2 标题（以通过 `validate:study`），内容为“占位导读 + 外链原文入口 + 后续制作提示”
  - original：按站内原文页格式最小可用（`### 标题` + 外链原文链接），不含 `Hxx` 高亮即可

- [ ] **Step 3: 执行脚本生成文件**

Run:
```bash
node scripts/generate-study-placeholders.mjs
```
Expected: 生成 v2–v4 目录项与对应 markdown 文件

- [ ] **Step 4: 运行内容校验**

```bash

```
Expected: `study content OK`
